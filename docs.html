Mod guide

Everything you need to restyle Musik or add features to it, without touching the app itself.

Introduction

A mod is a folder inside mods/. On launch Musik reads each folder, injects its CSS, then runs its JavaScript. 

mods/
  my-theme/
    manifest.json
    theme.css    # injected into <head>
    index.js     # runs sandboxed after the page is ready

Installing a mod

Drop the folder into mods/ next to the app and restart Musik. To remove it, delete the folder.

Only install mods from people you trust. They run inside the sandbox, but they can still change what you see.

manifest.json

Describes the mod. Name, version and author are the basics.

{ "name": "My Theme", "version": "1.0.0", "author": "you" }

Theme CSS

theme.css is injected into the page head, so it can override any style in the app. Set --accent to change the accent color.

Scripts

index.js runs once the page is ready and receives window.Musik. window.Aurelius still works as an old alias.

window.Musik

The API only grows. Existing keys are never removed or renamed.

Namespace Methods
player play, pause, seek, setVolume, getState, getCurrentTrack
library getTracks, getPlaylists
queue mirrors the queue manager
ui injectCSS, injectElement, removeElement, getView, onViewChange
events on, off, emit
theme setVar, getAccent

Events

Listen with Musik.events.on(name, fn).

Event Fires when
trackupdate the current track changes
play / pause playback starts or stops
seek the position jumps
artupdate album art changes
viewchange the user opens another page

Example mod

Musik.theme.setVar('--accent', '#ff6a5c');
Musik.events.on('trackupdate', t => {
  Musik.ui.injectElement('#np-badge', t.title);
});

Sandbox

Mods run in sandboxed frames or Workers inside the window, never in the main process. A broken mod can't freeze the app or stop your music.
