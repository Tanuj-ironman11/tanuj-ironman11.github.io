# Musik website

The site for [Musik](https://github.com/Tanuj-ironman11/Musik), a free desktop music player for your own files.

**Live:** https://tanuj-ironman11.github.io

## Run it locally

Open `index.html`, or serve the folder with any static server. Use a server if you want the accent color to follow the screenshots, since browsers block that over `file://`.

## Layout

- `index.html`, `style.css`, `app.js`: the site
- `assets/`: screenshots, icons, preview image
